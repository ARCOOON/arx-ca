# arx-rootca

A Go-based Root Certificate Authority API server built on the [step-ca SDK](https://github.com/smallstep/certificates). It exposes a RESTful HTTP interface for PKI operations while keeping the CA engine lean, secure, and suitable for future WebUI integration.
